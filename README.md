# Mini Search Engine

A Python-based mini search engine that supports text indexing and keyword search using basic information retrieval techniques.

## Features
- Simple text indexing
- Keyword-based search
- Lightweight and easy to run
- Built with Python

## Technologies Used
- Python
- Basic Information Retrieval concepts

## Project Description
This project is a simplified search engine that allows indexing of text files and searching through them using keywords. It demonstrates core concepts of information retrieval such as tokenization and indexing.

## How it works
1. The system reads and indexes text documents.
2. It processes user queries.
3. It returns the most relevant results based on keyword matching.
